measured on the locked toolchain with a full `npm run build` followed by `npm run size:check`.

`fd177c38` (16.0.18) to `81dba72a` (16.0.19, player-season view + OCR work), which was then merged
into the release branch. The ledger below is the Phase 0 baseline against 16.0.18; the release
transition exception therefore targets the real predecessor 16.0.19. Caps were re-measured after
the merge (`scripts/check-size.mjs`).

- `css/atmosphere.css` declared 15 opt-in `.u-*` utilities with **zero consumers** anywhere in
  HTML, JS, tabs, games, or locale data. The sheet is linked by index/admin/eden-x1/eden-x2/
  arcade and precached by `public/sw.js`, so the file itself stays; only the dead utilities were

## Static motion census

Parsed stylesheet count (upper bound; `display:none`-gated animations do not run):

- 40 CSS sources, 119 `@keyframes` definitions.
- 69 rules with an `infinite` animation after the reclaim (71 before; the two removed were the
  dead `u-shimmer` and `u-pulse`).
- Heaviest files: `app.css` (17 infinite rules), `ocr-dashboard.css` (14), `ai-launcher-critical.css`
  (9), `ai-assistant.css` (9), `ocr-dashboard-admin.css` (6), `eden-x1.css` (4).
- 16 infinite animations touch a repainting property; they are baselined in
  `scripts/check-motion-css.mjs` and guarded by `tests/unit/motion-css-infinite-paint.test.mjs`.
  New infinite paint animations fail `npm run test:unit`.

The old draft's "84 running animations on the live home page" cannot be reproduced from a
stylesheet and remains unverified; a browser-level census is an Open item.

## Core runtime allocation

`js/fx/motion-policy.js` measures 1,921 B minified / **890 B minified gzip** and
`js/fx/pointer-vars.js` 2,119 B / **894 B gzip** — 1,784 B gzip together, inside the plan's
≤3 KiB gzip core target. The proposed `js/fx/frame-loop.js` scheduler was dropped during the
16.5.1 review: every included effect is CSS or WAAPI, so no feature needed a shared rAF
scheduler, and the plan forbids shipping empty scaffolding. The 3,190 B / 1,266 B figure above
measured that module together with the policy; the remaining core is smaller, not larger.
